## Overview

**xPack GNU Arm Embedded GCC** is a
standalone, cross-platform (Windows, macOS, GNU/Linux) binary
distribution of GNU Arm Embedded GCC,
aimed at reproducible builds.

<CommonDetailsReproducibleBuilds />

<ProjectOverview/>

The open source **xPack GNU Arm Embedded GCC** project is hosted on GitHub as
[`xpack-dev-tools/arm-none-eabi-gcc-xpack`](https://github.com/xpack-dev-tools/arm-none-eabi-gcc-xpack/);
it provides the platform specific binaries as
[release assets](https://github.com/xpack-dev-tools/arm-none-eabi-gcc-xpack/releases).

In addition to the binary archives and the package metadata,
this project also includes the
[build scripts](https://github.com/xpack-dev-tools/arm-none-eabi-gcc-xpack/tree/xpack/build-assets/scripts).
