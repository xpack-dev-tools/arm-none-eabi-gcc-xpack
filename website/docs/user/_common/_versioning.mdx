## Versioning

The version string used by the
upstream {props.upstreamName ? props.upstreamName : 'GNU Arm Embedded GCC'} project
is a three number string
like <code>14.2.1</code>;
to this string the xPack distribution adds a fourth number,
but since [SemVer](https://semver.org) allows only three numbers,
all additional ones can
be added only as pre-release strings, separated by a dash,
like <code>14.2.1-<b>1.1</b></code>. When
published as a npm package, the version gets
a fifth number,
like <code>14.2.1-1.1.<b>1</b></code>.

Since adherence of third party packages to SemVer is not guaranteed,
it is recommended to avoid referring to the xPack GNU Arm Embedded GCC dependency via
a SemVer expressions
like <code>^14.2.1-1.1</code> or <code>~14.2.1-1.1</code>, and
prefer exact matches,
like <code>14.2.1-1.1.1</code>.
